## F1. All-skipped pytest tests receive characterization Red and Green evidence

**Repro**
```sh
cd dogfood-7/findings/repro-app021-skipped
python3 reproduce.py
```
The persistent fixture contains one annotated pytest test which calls `pytest.skip`
before any assertion, a T1 test-only REQ, and the auto-detected pytest runner.
The reproduction resets only its own ledger, then runs init, characterization Red,
Green and the full gate.

**Actual:** pytest prints `1 skipped`; Red exits 0 and is recorded as weak
characterization evidence, Green exits 0, and the full gate reports PASS with
`1/1 tests Red→Green`. No assertion ran.

**Expected:** Red (including characterization) and Green must reject an
all-skipped pytest selection. This is promised by enforced-rules.md and the
command's own rejection text.

**Location:** `.github/skills/lean-sdd-tdd/scripts/sdd.mjs:2166–2173`,
`cmdTdd` allSkipped/noAssert/zero detection; pytest's `1 skipped` summary is
not recognized. `NO_PASSED` at line 692 handles other runner formats but not
pytest's quiet output.

**Workaround:** Manually check selected pytest summaries and prohibit skip-only
evidence; do not use characterization to certify skipped tests. Run actual
assertion tests separately.

**Severity:** high.

## F2. Changing a Python imported alias target does not invalidate Red evidence

**Repro**
```sh
cd dogfood-7/findings/repro-app021-import
python3 reproduce.py
```
The fixture's unchanged implementation contains `wrong() -> 0` and `right() -> 1`.
The test asserts `read() == 1`. The reproduction records Red with
`from source import wrong as read`, changes only that import to
`from source import right as read`, then requests Green. It disables bytecode
writing to avoid Python's same-second same-size `.pyc` caching.

**Actual:** Red fails `assert 0 == 1`. After changing the alias binding, Green
is accepted with exit 0 without any new Red or implementation change.

**Expected:** Changing the meaning of the test's imported binding must invalidate
its Red hash and refuse Green until a new failing Red is established. This
is not harmless addition of a name to an import list.

**Location:** `.github/skills/lean-sdd-tdd/scripts/sdd.mjs:48–50`,
`normImports`: the Python normalization replaces the entire
`from source import ...` line with `from source`; `testShaVariant` incorporates
this normalized preamble. The Green guard at approximately lines 2129–2135
therefore treats behaviorally different tests as identical.

**Workaround:** Do not alter aliased import bindings between Red and Green.
Explicitly re-record Red after import changes; reviewers must inspect bindings
because the script cannot enforce this invariant.

**Severity:** high.
