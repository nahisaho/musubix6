## F1. init omits independent nested Go modules when the root has go.mod

**Repro**

```sh
sh dogfood-7/findings/repro-app029-2/repro.sh
```

The fixture has a root Go module with one passing, explicitly characterized
contract test, plus an independent `child/go.mod` with a failing ordinary test.
It runs `init`, Red/Green and the **full** gate with cwd and `--root` both equal
to the fixture directory. No `gate --changed` is involved.

**Actual**

`init` writes only the root `go test ./...` check and no `projects`.
The full gate reports `SDD GATE PASS`, exit 0. A separate
`cd child && go test ./...` fails with “nested Go module must be checked”.
Root-module `go test ./...` excludes directories containing another `go.mod`.
Evidence: `app029-go-sql-wire/.sdd/nested-go-module.log`.

**Expected**

Each independently bounded Go module should get its own project/check even
when the root is also Go. At minimum, init must warn that the nested module is
not checked and explain the necessary explicit configuration; it must not
treat Go modules like JS workspaces whose root runner covers the children.

**Location**

`.github/skills/lean-sdd-tdd/scripts/sdd.mjs:459-463`, `detectProjects(skipEco)`:
all nested manifests of a root-owned ecosystem are discarded.
`cmdInit`, line 699, puts `go` into that skip set whenever root `go.mod` exists.
The resulting root check is `go test ./...`, which cannot cross module boundaries.

**Workaround**

Add `projects: [{root: "child", testCmd: ["go","test","./...","-run","{IDU}(_|$)"],
checks: [{name: "test", cmd: ["go","test","./..."]}]}]` to `.sdd/config.json`
and add `dependsOn` paths where appropriate. Keep the root check as well.
Verified: this explicit configuration changes the fixture's full gate to
exit 1 with `cmd child:test` failure; see `.sdd/nested-go-workaround.log`.

**Severity:** med — a complete nested module's failing suite is absent from
the default full gate, and annotated tests there also use the wrong root runner.

Duplicate exclusion: the known nested changed-root skip, promoted-method
impact omission, and destructive external `_stub.go` collision were reproduced
but are not reported again. No files under `.github/` were changed.
