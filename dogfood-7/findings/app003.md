## F1. TypeScript stub generation leaks methods from sibling tests

**Repro** (from the repository root):
```sh
node dogfood-7/findings/repro-app003-1/repro.mjs
```
The fixture contains `TEST-STUB-001`, which calls `new Box().first()`, and a separate
`TEST-STUB-002`, which calls `new Box().second()`. The script resets only its generated
fixture file, initializes SDD and executes `tdd stub TEST-STUB-001`.

**Actual:** `src/box.ts` contains both `first()` and `second()`.
The app's first `tdd stub TEST-GRAPH-001` likewise generated `closure`, `replace`,
`dependencies` and `dependents`, used only in later test bodies.

**Expected:** Generate methods referenced by the requested test and shared preamble only.
`references/stubs.md` explicitly promises requested-test scope, and `stubFor` computes that scope.

**Location:** `.github/skills/lean-sdd-tdd/scripts/sdd.mjs`, `stubFor`, approximately
lines 1708 and 1728–1731. `scoped` is computed, but JS/TS `prep()` still constructs its
`S` and namespace member list from full-file `src`; `exportOf`/`methodsOf` therefore
see sibling test bodies.

**Workaround:** Hand-write missing scoped stubs, or put each test in its own file;
inspect generated stubs before trusting requested-test isolation.

**Severity:** med — generator modifies more API surface than the requested test requires;
can append unrelated throwing methods to existing classes.

## F2. Nested-root changed gate falsely passes without TDD evidence

**Repro** (from the repository root; fixture is deliberately not a separate Git repository):
```sh
node dogfood-7/findings/repro-app003-2/repro.mjs
```
The fixture has one T1 requirement, correctly annotated implementation and passing test,
but **no ledger and no Green evidence**. It invokes the same gate twice using
`--root dogfood-7/findings/repro-app003-2`, first with `--changed`, then without it.

**Actual:**
```text
gate --changed: SDD GATE PASS; tdd evidence (changed scope): 0/0 tests Red→Green; exit 0
gate:          SDD GATE FAIL; TEST-SCOPE-001: no Green recorded; exit 1
```
The full app also repeatedly reports `0/0` changed-scope tests despite all of its new
sources, specs and tests being untracked under the parent repository.

**Expected:** Scope actual files below the supplied root and reject missing evidence;
the changed gate should inspect this changed test and exit 1. Paths outside the
selected root should not enter its scope.

**Location:** `.github/skills/lean-sdd-tdd/scripts/sdd.mjs`, `changedFiles`, lines
2291–2295. `git status --porcelain -uall` runs with `cwd: ROOT`, but porcelain paths
are relative to the **Git top-level**, not `ROOT`. They are returned without
rebasing/filtering, while annotated test paths are root-relative; intersections are empty.

**Workaround:** Run the documented **full gate** (without `--changed`) for nested roots.
The application README calls out this limitation; the final full gate verified all
47 tests' evidence and passed.

**Severity:** high — the enforcement tool emits a success verdict while silently
omitting every changed test's required Red→Green evidence.
