## F1. Nested --root makes gate --changed silently omit local evidence and project checks

### Repro

Run from the musubix6 repository root against the provided minimal fixture:

```sh
node .github/skills/lean-sdd-tdd/scripts/sdd.mjs --root dogfood-7/findings/repro-app005-1 gate --changed
node .github/skills/lean-sdd-tdd/scripts/sdd.mjs --root dogfood-7/findings/repro-app005-1 gate
```

Fixture: `dogfood-7/findings/repro-app005-1/` contains one T1 requirement, a passing annotated
implementation/test and a test check. It intentionally has **no TDD ledger**. All fixture files are new
under a subdirectory of the existing Git repository; no separate Git initialization or commit is needed.

### Actual

The first command exits **0**, reporting:

```text
SDD GATE PASS
✓ trace: 1 REQ, 0 errors
✓ ledger: 0 entries, chain intact
✓ tdd evidence (changed scope): 0/0 tests Red→Green
✓ cmd test
```

The full gate exits **1** and correctly reports `TEST-REPRO-001: no Green recorded`.

The real workspace app independently reproduced `0/0` instead of `43/43` changed tests.
With explicit `.sdd/config.json` projects, every package check was skipped as having no changed files
despite every package being newly untracked. Unrelated outer-repository paths were also treated as
root-owned configuration changes.

### Expected

Changed paths must be normalized relative to the requested `--root`, and paths outside that root
must be excluded. The new fixture test must require evidence and cause exit 1.
The new app's five package checks must run, with all 43 tests' evidence included.

### Location

`.github/skills/lean-sdd-tdd/scripts/sdd.mjs:2291–2295`, `changedFiles()`.
It runs `git status --porcelain -uall` from `ROOT`, but Git emits **repository-root-relative** paths,
which are inserted unchanged into the set. `listFiles()`/entity paths are **requested-root-relative**.
Consequently `cmdGate()`'s `ch.has(e.path)` / `ch.has(s.path)` at approximately 2494–2498 cannot match,
and project check selection at approximately 2560 also cannot match.

### Workaround

Use the documented full `gate` without `--changed` whenever the requested root is nested in a Git
repository. The app's final full gate passes 43/43 evidence, typecheck, root tests and all five project
checks. No skill files were modified.

### Severity

**high** — a requested evidence gate reports PASS with no Red/Green evidence and can skip all relevant
workspace checks. The defect affects the prescribed dogfood `--root <app dir>` workflow itself.
