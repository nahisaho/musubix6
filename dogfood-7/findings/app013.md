## F1. Python module stubs leak names from unselected tests

**Repro** (from repository root):
```sh
cd dogfood-7/findings/repro-app013-1
python3 reproduce.py
```
The fixture imports `from scope_demo import api`; selected TEST-SCOPE-001 calls
`api.first()`, while TEST-SCOPE-002 alone calls `api.unrelated()`. It resets only
the generated fixture module, runs `init` and `tdd stub TEST-SCOPE-001`, then
inspects the generated AST.

**Actual:** `src/scope_demo/api.py` contains both `first` and `unrelated`.
The unrelated test was not selected.

**Expected:** Only `first` is generated. `references/stubs.md` specifically says
all Python names come from the requested test's scope only (#147), and the
general stub contract promises per-test scoping.

**Location:** `.github/skills/lean-sdd-tdd/scripts/sdd.mjs`,
`stubFor`, lines 1777–1780. Submodule detection and function extraction use `src`
rather than the already computed `scoped` input (line 1708).

**Workaround:** Write scoped modules manually, or separate tests into files
before generating module stubs. Inspect generated names before recording Red.

**Severity:** med — unexpected persistent code generation breaks scope guarantees
and can change the starting state of independent feature cycles.

## F2. Aliased Python submodule imports are stubbed as functions

**Repro** (from repository root):
```sh
cd dogfood-7/findings/repro-app013-2
python3 reproduce.py
```
The fixture imports `from alias_demo import api as renamed`, then asserts
`renamed.first() == 1`. The reproducer resets only its fixture outputs and runs
`init`, `tdd stub TEST-ALIAS-001`, and pytest.

**Actual:** The generator appends `def api(*a, **k)` to `alias_demo/__init__.py`.
It does not create `alias_demo/api.py`. Pytest fails with
`AttributeError: 'function' object has no attribute 'first'`, not a throwing
stub for the requested behavior.

**Expected:** Generate `alias_demo/api.py` containing `first`, recognizing that
`renamed` is the local alias of the imported submodule `api`.

**Location:** `.github/skills/lean-sdd-tdd/scripts/sdd.mjs`,
`stubFor`, line 1763 discards aliases; lines 1777–1780 search for the original
imported name in call sites. The alias-to-import mapping is never retained.

**Workaround:** Use an unaliased import during stub generation, or hand-write
the missing submodule and then keep the real aliased import unchanged.

**Severity:** med — common valid Python import syntax produces the wrong API
shape and a misleading behavior failure.
