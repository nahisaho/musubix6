## Design
Extend root load classification by the native loader error-code family, not TypeError generally; retain the existing assertion, runtime-failure and missing-deliverable exclusions. Node20 lacks native TS; Node22/24 accept --no-experimental-strip-types to reproduce actual unsupported TS. Inventory before edits: internal/modules/esm/{get_format,load,loader,resolve,initialize_import_meta} and internal/modules/typescript reference ERR_UNKNOWN_FILE_EXTENSION, ERR_UNKNOWN_MODULE_FORMAT, ERR_UNSUPPORTED_ESM_URL_SCHEME, ERR_UNSUPPORTED_DIR_IMPORT, ERR_UNSUPPORTED_RESOLVE_REQUEST, ERR_UNSUPPORTED_NODE_MODULES_TYPE_STRIPPING and ERR_UNSUPPORTED_TYPESCRIPT_SYNTAX. The last is already classified by existing SyntaxError handling and needs no new branch. No new runners, dependencies, old-fixture edits, compiler/closure changes or broad G5 policy.
