## Design
Keep .github/skills as the single canonical payload; copy unchanged bytes into host-selected roots, with no generated host-specific variants. Parse/validate the complete init request and watchdog policy before any mkdir/copy; do not promise rollback on filesystem failures.
Policy: copilot supports all 10 skills; claude supports all except watchdog; both is their union with per-host filtering. Explicit incompatible selection fails before applying skip/force. Default list stays unchanged; installed/skipped messages identify host paths.
Use skill-relative placeholders and host-native question tools (Copilot ask_user / Claude Code AskUserQuestion); if unavailable, obtain explicit user confirmation in conversation and stop before approval recording. Do not introduce fake tool shims or auto-approve.
## Assumptions / risks
Six first-failure stages: contract—explicit support table; trusted inputs—validate full request before writes; execution—copy/runtime/permissions may fail explicitly, no transactional rollback; verdict—assert bytes/exit codes and valid controls; history—preserve old approvals/qualification, record new Red/Green/mutations; integration/distribution—real tgz and installed paths, never reuse v0.1.x release evidence.
